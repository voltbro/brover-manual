# Изменение пароля

На **BRover-E5** по умолчанию используется стандартный пароль пользователя `pi`. В целях безопасности рекомендуется изменить его при первом использовании устройства.

Также при работе через браузер используется пароль для доступа к **code-server**, который при необходимости также можно изменить.

:::note
Стандартный пароль по умолчанию: `brobro`
:::

:::warning[Внимание]
Для смены пароля вам необходимо знать текущий пароль или иметь права `sudo`.
:::
---

## Изменение пароля пользователя через SSH

Самый простой способ — изменить пароль, подключившись к роверу по SSH.

1. Подключитесь к устройству:

```bash
ssh pi@broverXX.local
```

2. Запустите утилиту `passwd`:

```bash
passwd
```

:::note
При вводе пароля символы не отображаются — это мера безопасности.
:::

3. Следуйте подсказкам:

* Введите текущий пароль.
* Введите новый пароль.
* Подтвердите новый пароль.

---


<details>
<summary>Альтернативная смена пароля пользователя: chpasswd</summary>

При наличии прав `sudo` пароль пользователя можно установить одной командой:

```bash title="На ровере, в SSH-сеансе"
echo "pi:новый_пароль" | sudo chpasswd
```


</details>

## Изменение пароля code-server

Пароль для доступа к **code-server** используется при входе через браузер.

1. Подключитесь к устройству по SSH

2. Откройте файл конфигурации:

```bash
nano ~/.config/code-server/config.yaml
```

3. Найдите параметр `password` и укажите новый пароль:

```yaml
password: your_password
```

4. Сохраните файл и перезапустите сервис:

```bash
sudo systemctl restart code-server@pi.service
```

5. Выйдите из code-server и проверьте вход с новым паролем.

---

## Изменение через скрипт change_pi_params.sh

На устройстве доступен скрипт автоматической настройки параметров:

```bash
sudo /home/pi/change_pi_params.sh
```

Скрипт позволяет:

* изменить имя хоста
* установить одинаковый новый пароль для пользователя `pi` и code-server
* обновить системные файлы (`/etc/hostname`, `/etc/hosts`) и конфигурацию code-server

В процессе выполнения скрипт последовательно запросит:

* новое имя устройства
* новый пароль для пользователя `pi` и code-server
* подтверждение нового пароля

:::tip[Имя можно сохранить]

Если менять имя устройства не требуется, введите текущее имя, например `brover01`.

:::

Для изменения только одного пароля используйте соответствующий самостоятельный способ на этой странице.

:::warning[Автоматическая перезагрузка]

После успешного изменения параметров ровер автоматически перезагрузится через 3 секунды. Текущее SSH-соединение прервётся. Дождитесь загрузки и подключитесь по указанному при настройке имени устройства.

:::

## Проверка

Попробуйте подключиться к устройству с новым паролем:

```bash
ssh pi@broverXX.local
```

Если вход выполняется успешно — пароль изменён корректно.

Если вы изменили имя устройства через скрипт, используйте новое имя вместо `broverXX`.
