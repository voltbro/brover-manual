# Обзор способов подключения

BRover-E5 поддерживает несколько способов удалённого подключения для управления, разработки и передачи файлов. Выбор метода зависит от задач: от выполнения команд до полноценной разработки.

## Доступные методы подключения

1. **SSH (терминал)**
   Базовый способ доступа к системе:

   * выполнение команд
   * запуск ROS-нод
   * диагностика и отладка

2. **Веб-интерфейс**
   Быстрый способ проверить работу ровера и управлять им из браузера:

   * управление с клавиатуры
   * видеопоток с камеры
   * просмотр базовых данных

3. **VS Code (code-server или Remote-SSH)**
   Среда для разработки:

   * редактирование кода
   * работа с файлами проекта
   * удобная навигация по коду

4. **Fast DDS**
   Способ подключить внешний компьютер к ROS 2-сети ровера:

   * просмотр топиков и сервисов ровера
   * запуск ROS-нод на рабочем компьютере
   * работа через Discovery Server или Simple Discovery


## Общие требования

Для подключения к роверу компьютер, планшет или телефон должны иметь сетевой доступ к устройству.

Это может быть:

* подключение к той же Wi-Fi-сети, что и ровер;
* подключение к fallback-точке доступа ровера;
* прямое Ethernet-подключение к Raspberry Pi ровера.

Стандартные учётные данные:

* **Логин:** `pi`
* **Пароль:** `brobro`
* **Имя хоста (Hostname):** `broverXX.local` (где `XX` — номер устройства)

## Сетевые сценарии подключения

### Wi-Fi-сеть по умолчанию

При первом запуске **BRover-E5** пытается подключиться к заранее настроенной сети:

```yaml
SSID: TurtleBro
password: turtlew001
```

или

```yaml
SSID: TurtleBro5G
password: turtlew001
```

:::note
Поэтому мы рекомендуем использовать именно такие настройки Wi-Fi роутера для работы с ровером
:::

### Wi-Fi fallback

Если ровер не смог подключиться к известной Wi-Fi-сети, он может перейти в режим точки доступа.

В этом режиме подключитесь к Wi-Fi-сети с именем хоста ровера, например `brover01`, и используйте пароль `turtlew001`.

После подключения ровер доступен по адресу `192.168.50.1`.

### Ethernet fallback

Если Wi-Fi работает нестабильно, можно подключить Ethernet-кабель напрямую к Raspberry Pi ровера и к компьютеру.

В этом режиме ровер доступен по адресу `192.168.123.1`.

Подробнее см. раздел [Сетевой fallback](../40-network-fallback.md).

## Какой способ выбрать

| Метод | Когда использовать | Сложность |
| ----- | ------------------ | --------- |
| **Веб-интерфейс** | Быстрая проверка, ручное управление, работа с телефона | Легко |
| **SSH** | Диагностика, выполнение команд, обслуживание | Легко |
| **VS Code** | Разработка и работа с кодом | Средне |
| **Fast DDS** | Подключение к ROS 2-сети ровера | Сложно |
| **Wi-Fi fallback** | Если ровер не подключился к обычной Wi-Fi-сети | Легко |
| **Ethernet fallback** | Если нужен надёжный доступ без Wi-Fi | Легко |


:::tip[Совет]
Для первого подключения используйте веб-интерфейс или SSH.
:::
