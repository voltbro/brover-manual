# Веб-интерфейс

Веб-интерфейс позволяет управлять ровером из браузера и просматривать основные данные без установки дополнительного ПО.

Через веб-интерфейс можно:

* управлять ровером с клавиатуры;
* управлять ровером с мобильного устройства через виртуальный джойстик;
* изменять максимальную скорость движения;
* получать видеопоток с одной или нескольких камер;
* просматривать данные одометрии;
* сбрасывать одометрию;
* просматривать напряжение аккумуляторной батареи;
* просматривать состояние Wi-Fi-подключения;
* быстро перейти к VS Code Web и онлайн-инструкции.

Видеопоток в веб-интерфейсе формируется из ROS-топиков камеры. За получение изображения отвечает нода `/camera1`, а за публикацию потока по HTTP — `/web_video_server`.

## Требования

Компьютер, планшет или телефон должны иметь сетевое подключение к роверу.

## Подключение к веб-интерфейсу

<Tabs groupId="web-interface-connection">
<TabItem value="hostname" label="По имени хоста" default>

Откройте в браузере:

```bash
http://broverXX.local:8080
```

где `XX` — номер ровера, указанный на корпусе Raspberry Pi.

Пример:

```bash
http://brover15.local:8080
```

</TabItem>
<TabItem value="ip" label="По IP-адресу">

Если имя хоста не открывается, используйте IP-адрес ровера:

```bash
http://<IP-адрес ровера>:8080
```

Пример:

```bash
http://192.168.1.115:8080
```

Если IP-адрес неизвестен, найдите его в интерфейсе роутера или через сетевой сканер. Подробные способы описаны в разделе [SSH-подключение](20-ssh-connection.md#определение-ip-адреса-ровера).

</TabItem>
<TabItem value="wifi-fallback" label="Wi-Fi fallback">

Если ровер перешёл в режим Wi-Fi fallback, подключитесь к его точке доступа и откройте:

```bash
http://192.168.50.1:8080
```

Параметры fallback-точки доступа:

```bash
SSID: имя хоста ровера, например brover01
Password: turtlew001
```

Подробнее см. раздел [Сетевой fallback](../40-network-fallback.md).

</TabItem>
</Tabs>

## Основные элементы интерфейса

В верхней панели отображается статус подключения к ROS. Если соединение с `rosbridge_server` недоступно, веб-интерфейс показывает, что ROS недоступен.

Основная область интерфейса содержит видеопоток с камеры. Если в системе обнаружено несколько видеотопиков, интерфейс показывает вкладки для переключения между камерами.

В правой панели отображаются:

* координаты `X` и `Y`;
* угол поворота ровера;
* напряжение аккумуляторной батареи;
* состояние Wi-Fi-подключения;
* регулятор максимальной скорости;
* кнопки управления движением `W`, `A`, `S`, `D`;
* кнопка сброса одометрии.

На мобильных устройствах используется отдельная панель управления с виртуальным джойстиком, краткой информацией о Wi-Fi и напряжением батареи.
