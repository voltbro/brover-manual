# Первое подключение

После первого включения подключитесь к роверу одним из доступных способов:

* через обычную Wi-Fi-сеть, к которой подключён ровер;
* через Wi-Fi fallback-точку доступа ровера;
* через прямое Ethernet-подключение.

По умолчанию ровер пытается подключиться к одной из сетей:

```bash
SSID: TurtleBro / TurtleBro5G
Password: turtlew001
```

Если ровер не смог подключиться к известной Wi-Fi-сети, примерно через 60 секунд он может перейти в режим Wi-Fi fallback.

## Резервное подключение через Wi-Fi fallback

Если ровер не смог подключиться к известной Wi-Fi-сети, он создаёт собственную Wi-Fi-точку доступа:

```bash
SSID: имя хоста ровера, например brover01
Password: turtlew001
```

После подключения к этой сети ровер доступен по адресу:

```bash
192.168.50.1
```

Веб-интерфейс в этом режиме открывается по адресу:

```bash
http://192.168.50.1:8080
```

Если требуется надёжное прямое подключение без Wi-Fi, используйте Ethernet fallback.

Подробнее см. раздел [Сетевой fallback](../40-device-operation/40-network-fallback.md).

## Подключение по SSH

Для первой проверки используйте SSH:

```bash
ssh pi@broverXX.local
```

где `XX` — номер ровера, указанный на корпусе Raspberry Pi.

Если подключение по имени хоста не работает, найдите IP-адрес ровера в интерфейсе роутера и подключитесь по IP:

```bash
ssh pi@<IP-адрес ровера>
```

Учётные данные по умолчанию:

```bash
Логин: pi
Пароль: brobro
```

## Веб-интерфейс

Для управления из браузера откройте:

```bash
http://broverXX.local:8080
```

или:

```bash
http://<IP-адрес ровера>:8080
```

## code-server

Для работы с файлами и кодом через браузер откройте:

```bash
http://broverXX.local:8090
```

или:

```bash
http://<IP-адрес ровера>:8090
```

Пароль по умолчанию:

```bash
brobro
```
